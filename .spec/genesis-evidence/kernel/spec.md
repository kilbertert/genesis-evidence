# kernel

项目里所有"同一个判断只能有一处真值"的地方。这一层不 import 存储、不做 IO、不认识 HTTP，
因此任何一层都可以安全引用它而不制造回边。

## 为什么单独成层

这些模块的共同历史是：同一条规则曾被复制到 Python、SQL CHECK、前端 JS 和测试夹具里，副本随后各自漂移，
表现为"界面说 low 会被扣下，服务端却放行"这类事实性错误。把规则收进无依赖模块，是让"改一处就全改"成为结构事实，
而不是纪律要求。

## 边界

- 只含词表、判定谓词、投影函数、纯数据结构。
- 不做事务、不读库、不发请求、不读环境变量。
- 需要持久化时，由 [[persistence]] 提供 SQL 谓词（例如 `patient_visible_sql`），而不是在本层拼查询。
