# 0005: 审核工作台采用独立阅读区域

Status: Accepted

Date: 2026-08-29

Parent: PRD #103

## Context

论文队列和审核步骤都可能很长。原工作台让页面整体增长，浏览器滚动时队列与审核内容同步移动，审核员会丢失队列上下文；所有步骤同时展开也增加了首屏阅读负担。

## Decision

桌面端将论文队列与审核内容设置为两个独立阅读区域，各自纵向滚动；论文身份摘要保持展开，只默认展开当前最先需要完成或人工处理的步骤。移动端恢复单列自然滚动。

## Alternatives Considered

- 继续整页同步滚动：实现简单，但长队列下无法保持导航上下文。
- 所有步骤继续展开：不改变信息可见性，但首屏噪音和扫描成本持续存在。
- 将每个步骤拆成独立页面：降低单页高度，但增加路由、状态保存和切换成本。

## Rationale

独立阅读区域解决已观察到的滚动缺陷，原生折叠保留全部审核内容并把注意力放在当前动作；移动端单列则避免在有限宽度下制造嵌套滚动。
